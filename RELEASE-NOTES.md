# ViceTogether alpha.11 - experimental

Ctrl+O opens a native Vice City style menu with Weapons, Cars, Motorcycles, Helicopters, Boats and Aircraft categories. Arrows or WASD navigate, Enter applies, Backspace goes back and Esc closes. Vehicle spawning is host-only and limited to eight vehicles; boats and the Skimmer require water. Missing ground falls back to a nearby road. Ctrl+I opens host-only controls for time, weather, clearing the host wanted level and removing unoccupied vehicles spawned from the menu. Up/down arrows provide bike and aircraft pitch input while the menu is closed. This is an initial menu, not a complete Menyoo equivalent.

Fixes the stale bike lean matrix that could leave a host passenger behind a guest-driven bike. Passenger entry preserves vehicle control status. Drive-by code safely rejects missing/non-player drivers, fixing the passenger-before-driver boat crash. Guest-driven vehicles receive host wreck transitions, and stock explosions replay once for newly received wrecks, including initial snapshots. Near-death respawn selects ground or a nearby road instead of leaving players airborne or underwater.

Verified with hidden, muted two-engine tests on one PC: keyboard navigation and host-only admin/spawning, shared Infernus and night clock, guest PCJ-600 driving with host passenger for about 90 metres, Maverick movement for 74 metres, Speeder movement for 384 metres, and Skimmer water movement for 52 metres. Skimmer takeoff has not been verified. A guest-driven car explosion produced native wrecks in both engines; both players died and respawned within about 66 metres of recorded death positions. These are local observations, not comprehensive visual or internet gameplay verification. All 35 unit tests pass.

Includes the top-left measured ping display, unordered replaceable snapshots, guest driving, solo hosting with late joins, friend notifications and multiplayer pause fixes. Reliable gameplay events retain reliable delivery. No promise of 20-40 ms latency or unrestricted NAT connectivity is made; no TURN relay or metered hosting is enabled.

Installed clients download updates from GitHub and apply them when the launcher exits. Finish playing, close the launcher to apply the update, then reopen it. Both players should use the same version. Portable clients replace their executable manually. Updates preserve cached game assets, profiles and saves; public installers contain no original GTA assets.

Remaining limitations: full police/NPC reactions, distant-area population simulation, shared pickups, all smoke/particle and vehicle damage effects, public lobby browsing, comprehensive cross-network gameplay and clean Windows first-run verification remain unfinished. World synchronization is not 1:1. Fifteen game modes remain deferred. This is a tested incremental update, not a final game release.
