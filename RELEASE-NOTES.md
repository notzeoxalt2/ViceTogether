# ViceTogether alpha.12 - experimental

Rejoining an existing native game clears the previous world sequence, remote-player histories and old guest population references. A hidden two-engine test forced an old world sequence of 1,000,000, reused the same running engine, then accepted sequence 83 and rendered seven NPCs. Leaving a vehicle during reset detaches the local player before removing old replicas. Dead NPC replicas no longer let a stale living pose immediately replace their initial death transition; comprehensive NPC death/combat animation testing remains unfinished.

Friends and lobbies use four public discovery endpoints that accepted test subscriptions and ephemeral setup messages. The removed default endpoint requested authentication. A hidden public-signaling test covered friend pairing, authenticated lobbies, solo hosting/late joins and launcher rejoin with stubbed launch handlers; its sampled authenticated lobby connection was about 0.8 seconds on one PC. Public services can rate-limit or become unavailable. This does not prove the reported five-minute wait is solved on two different networks, and it does not demonstrate 20 ms game latency.

All 36 unit checks pass. Includes alpha.11 vehicle menus, passenger/wreck fixes and the measured ping HUD. Installed launchers download updates from GitHub; finish playing and close/reopen the launcher to apply them. Both players should use the same version. Portable users replace their executable manually. Game assets, profiles and saves remain local and are not included in public installers.

Radmin native binary recovery is a separate private analysis artifact. No Radmin proprietary source, driver or DLL is bundled. No APK project or metered relay service is integrated. Direct WebRTC still depends on NAT/firewall conditions; there is no TURN fallback. Distributed NPC simulation, complete AI reactions, shared pickups, full world/particle parity, clean Windows testing and comprehensive two-network gameplay remain unfinished. This is an incremental experimental update, not a finished 1:1 release.
